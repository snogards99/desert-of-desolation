# Desert of Desolation v0.4.2 — Required Advanced Audio

- Supersedes the v0.4.1 optional-audio simplification.
- Google Drive remains the sole persistent game-state/media authority.
- ChatGPT plugin remains the gameplay/orchestration layer.
- GitHub-hosted advanced audio is now a required session-readiness prerequisite.
- Railway remains excluded.
- Readiness is checked once per session, not on every turn, to keep the game architecture simple.
- If readiness fails, campaign state must not advance.
