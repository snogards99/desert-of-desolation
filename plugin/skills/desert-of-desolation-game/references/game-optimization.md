# Game Optimization Gates

Use these gates for maintenance passes without advancing campaign state.

1. Turn latency: no broad Drive search or optional media fetch blocks the current action.
2. Agency: no player-controlled action is invented.
3. Mechanics: consequences precede narration; no narration predicts uncommitted results.
4. Discovery: no preload/media/options leak hidden information.
5. Combat clarity: tactical state remains recoverable after every combat beat.
6. Narrative economy: atmosphere adds tension or information; repeated filler is removed.
7. NPC quality: dialogue is persona/source consistent and purposeful.
8. Media: current-scene essentials outrank successors; stale work cancels.
9. Audio: only renderer acknowledgement establishes PLAYING; stale epochs cannot play.
10. Resume: checkpoints reconstruct state/media semantically without replaying stale one-shots.
