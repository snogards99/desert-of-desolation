# Visual authority - plugin 1.4.1

Apply `../data/VISUAL_THEME.json` and the sibling `../../desert-of-desolation-art-direction/SKILL.md` to future visual output. TITLE_SPLASH/HOME use DOD_SITE; ordinary gameplay defaults to DOD_INK; chapter/major discovery/climax uses DOD_PAINTED. Shared tokens and templates live in that skill.

This supersedes the former green/black pixel-art style in `../data/imagery/index.json`, the visual style rows in `architecture_contract.jsonl`, and old baked prompt text in the workbook/JSONL. Preserve those old files and IDs as provenance. Reconstruct new prompts from source-verified, currently visible scene descriptions instead of stacking new instructions onto old prompts. The ink mode is not a desaturated painting.

Keep the 361-node inventory and all existing background/actor/composite relationships, death gates, independent instance states and A/B/C phase semantics. No planned asset becomes available merely because the style changed. All existing missing node imagery remains unavailable.

Use the supplied eye emblem; no new logo has been invented. The added color/size icon files are mechanical derivatives. Original series crops in the art-direction skill are private design references, not runtime node art or proof of public reuse permission. Existing legal text, logos and licensing links in the actual Site remain host-owned.

Read `../../desert-of-desolation-art-direction/references/site-integration.md` before applying theme assets to the existing private Site. No live Site theme update, new artwork generation, audible campfire test or physical-device QA is implied by this plugin release. Theme code never creates an audio context, fetches sound, changes a save, reveals a secret catalogue or replaces the current game engine.
