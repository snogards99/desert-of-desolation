Run these ten passes only when they reveal a real weakness. Reuse the existing private Site, preserve state, and do not repeat the verified 397-file migration.

1. **Identity** — verify existing project/URL/private audience; no duplicate Site.
2. **Title/home integration** — apply bundled DOD_SITE masters as visual references while rendering Continue, New Game, sound, navigation and legal content as real semantic controls.
3. **Mobile layout** — one-thumb iPhone flow, safe areas, large targets, no horizontal scroll/hover-only controls.
4. **Audio activation** — real user gesture unlock; decode/simulation alone does not pass.
5. **Persistent audio shell** — one context across ordinary node/UI changes; preserve mute/volume.
6. **Seven-bus mix** — Narrator, Dialogue, Creature Presence, Movement, Event/SFX, Ambience, Music; speech/mechanics outrank decoration.
7. **Cue lifecycle** — bounded preload, stale speculative cancellation, no duplicate loops or delayed abandoned SFX.
8. **Media resolution/fallback** — deterministic ID -> verified Site asset only after cutover, else bundled rollback, else static/text/silence.
9. **Failure recovery** — cache/network/decode/reconnect failures never block gameplay or duplicate playback.
10. **Evidence/cutover** — update `SITE_RUNTIME_QA.json`; approve Site-primary only when every required `SITE_CUTOVER_CHECKLIST.json` gate passes. Record physical iPhone QA separately.
