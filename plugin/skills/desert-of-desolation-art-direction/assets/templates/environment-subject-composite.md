# Environment / subject / composite

Retain existing catalogue IDs. Begin with an approved environment A, then derive B/C using restrained ambient variation. Reuse the same actor design for each appropriate instance, with independent state. Pair A+A, B+B, and C+C. Never create nine combinations or duplicate the environment per actor.

Private record: module/edition, node ID, environment ID, design ID, instance ID, state, phase, camera/anchor lock, source reference, visibility gate, approval, actual path, SHA-256, safe public label.

Environment: only visible architecture and props; no implied occupants.
Subject: isolated approved appearance in normal/attack/dying/dead state, only where meaningful.
Composite: current visible subject instances placed on the same approved environment.

Attack is not a hit; dying requires a resolved lethal event; dead is static. Spectral disappearance can replace a corpse only when source-supported. Missing correct-state art becomes background plus text.
