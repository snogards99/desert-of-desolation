# DOD_SITE homepage

Use the approved desktop and mobile master UI references as the visual target for one responsive semantic homepage. Do not rasterize the whole application and do not place invisible hotspots over baked controls.

Desktop target: eye mark and narrow navigation; cinematic moonlit hero; large Desert of Desolation title; Continue Adventure primary action; New Game secondary action; four Explore/Play/Discover/Survive feature cards; retained legal/footer area.

Mobile target: compact eye/header, centered title, hamburger navigation, vertical hero, Continue Adventure immediately reachable, New Game secondary, two-column feature cards when space allows and one-column below narrow widths, stacked readable footer.

Use real headings, buttons, links, navigation, and legal text. The approved screenshots may be used as noninteractive splash/poster assets and visual QA references. Preserve the existing state/audio handlers behind real controls.
