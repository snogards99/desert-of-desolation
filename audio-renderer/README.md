# Desert of Desolation Audio Renderer

MCP Apps audio renderer for the Drive-authoritative Desert of Desolation game.

## Run
`npm install` then `npm start`. Default port: `8787`. Endpoints: `/healthz`, `/mcp`.

## GitHub Codespaces
The repository devcontainer forwards port 8787. Make the forwarded port accessible to ChatGPT only as needed and use its HTTPS URL plus `/mcp` for the MCP connection. Codespaces is the selected GitHub-native runtime for development/gameplay testing, not a claim of permanent production hosting.

No Railway configuration is used.
